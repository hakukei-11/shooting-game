## 確定事項

- Webブラウザで遊べるシューティングゲームを開発する。
- 主な開発・動作確認環境はデスクトップPCとする。
- GitHub正本：`hakukei-11/shooting-game` の `main`。
- ChatGPTからGitHubへの直接登録方式を標準運用とする（2026-11-21承認）。
- 通常作業は作業ブランチで行い、Pull Requestによる変更確認を基本とする。
- `main`への反映はユーザー承認後とする。
- Codexは複雑な実装・テストの補助として利用する。
- 重要な仕様変更には事前承認を要する。
