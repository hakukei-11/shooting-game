# GitHub運用手順書

## 状態

- 方針：承認済み（2026-11-21）
- 手順書：初版案（`main`反映前）

## 対象

- リポジトリ：`hakukei-11/shooting-game`
- 正本ブランチ：`main`
- 他リポジトリ（例：`kabuka`）は作業対象外

## 標準手順

1. 承認済み仕様・対象ファイル・変更目的を確認する。
2. `main`から作業ブランチを作成する。
3. ChatGPTからGitHubへ対象ファイルを作成または更新する。
4. 登録結果を読み戻し、変更内容・コミットIDを確認する。
5. `main`宛てにPull Requestを作成し、差分を確認する。
6. ユーザーの承認を得た後に限り、`main`へ反映する。
7. 変更結果と必要な進捗・変更管理報告を記録する。

## 権限・安全策

- `main`への無承認の書き込み・マージをしない。
- 重要な仕様・設計変更は事前承認を得る。
- APIキー、パスワード等の秘密情報をリポジトリに登録しない。
- GitHubへの書き込みが失敗した場合、成功扱いせずエラーと未反映状態を報告する。
- Codexは複雑な実装・テストの補助に用いる。
